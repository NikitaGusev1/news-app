# Backlog

## Fetchable Daily Digest

- **Server-side story cache:** Cache fetchable digest stories and extracted article text behind a `story_id`, so tapping a headline does not re-fetch the same URLs before analysis.
- **Manual fallback:** If digest coverage feels too small, add a flow where users can paste article text for missing sources.
- **Expanded source set:** Add more known-fetchable RSS sources after the first version proves stable.
- **Search within fetchable digest:** Search only across currently fetchable and grouped stories, keeping the reliability promise.
